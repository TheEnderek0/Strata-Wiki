POINT assault_assaultpoint

(Assault) assault point

KeyValues

Assault Hint Group <string>

NPC's movements are constrained to this hint group once assault has begun

Next assault point (optional) <target_destination>

No description provided.

Assault time out <float> = 3.0

This point is cleared when no enemies are seen for this long (seconds)

Clear on contact with enemies <boolean> = No

If you come in contact with enemies while approaching the assault point, clear our assault point

Allow diversion <boolean> = No

If you come in contact with enemies while approaching the assault point, divert to kill them. Resume the assault once contact is lost.

Diversion Proximity <float> = 0

If Allow Diversion is set, NPC will only divert from assault to attack an enemy that is within this distance of the assault point. 0 = No limit.

Never Timeout <boolean> = No

If set, the assault never ends for NPCs assaulting this point. Useful for forcing NPCs back to a point.

Strict? <choices> = No, NPC may move from point to attack (0)

No description provided.

Possible Values:

NameValue
No, NPC may move from point to attack0
Yes, NPC may not move to attack1

spawnflags <flags>

No description provided.

Possible Flags:

NameValueDefault
Clear this point upon arrival, UNCONDITIONALLY1❌

Force Crouch <boolean> = No

NPCs using this assault point are forced into crouching while holding it.

Urgent <boolean> = No

If true, NPCs will consider movement to this assault point as Urgent Navigation.

Attack Tolerance <choices> = Tight (3ft) (36)

How far this NPC may move from the assault point to try to attack an enemy.

Name <target_source>

The name that other entities refer to this entity by.

Global Entity Name <string>

Name by which this entity is linked to another entity in a different map. When the player transitions to a new map, entities in the new map with globalnames matching entities in the previous map will have the previous map's state copied over their state.

Pitch Yaw Roll (X Y Z) <angle> = 0 0 0

This entity's orientation in the world. Roll is the rotation around the X axis, pitch is rotation around the Y axis and yaw is the rotation around the Z axis.

Parent <target_destination>

The name of this entity's parent in the movement hierarchy. Entities with parents move with their parent. Set an attachment point via 'parentname,attachment'.

Inputs

SetClearOnContact <integer>

Set the clear on contact flag. NPCs who spot enemies while running to the assault point, or while waiting at it, will immediately Clear it.

SetAllowDiversion <integer>

Set the allow diversion flag. NPCs who spot enemies while running to the assault point, or while waiting on it, will divert away (leave Assault mode) to deal with the enemies. Upon losing enemies, they'll go back to Assault mode, and return to this assault point.

SetForceClear <integer>

Set the Force Clear flag. NPCs who are currently running to the assault point will Clear it immediately. NPCs who acquire it in the future will Clear it automatically.
