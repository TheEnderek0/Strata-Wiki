POINT env_fog_controller

An entity that controls the fog and view distance in the map.

KeyValues

Fog Enable <boolean> = No

Whether or not the fog should start enabled.

Fog Blend <boolean> = No

Enables color blending between the primary color and the secondary color. When looking at the Primary Fog Direction, the primary fog color will appear. When looking away, the secondary color will. Looking between directly at the direction and directly away will cause color blending.

Use Angles for Fog Dir <boolean> = No

No description provided.

Primary Fog Color <color255> = 255 255 255

The color of the fog. If fog blend is enabled, this color blends with the secondary color when not looking at the primary fog direction.

Secondary Fog Color <color255> = 255 255 255

The secondary fog color. If fog blend is disabled, this color will never appear.

Primary Fog Direction <string> = 1 0 0

If fog blend is enabled, this is the direction that shows only the primary color. Directly away is the secondary color and in-between the colors are blended.

Fog Start <string> = 500.0

The distance from the player the fog starts.

Fog End <string> = 2000.0

The distance from the player the fog reaches the Fog Max Density keyvalue.

Fog Max Density [0..1] <float> = 1

The max density the fog can get to, 0-1.

Interpolate time <float> = 0

The fade time for the StartFogTransition input.

Far Z Clip Plane <string> = -1

The distance at which the world will not be rendered.

spawnflags <flags>

No description provided.

Possible Flags:

NameValueDefault
Master (Has priority if multiple env_fog_controllers exist)1❌

HDR Color Scale <float> = 1

Float value to multiply fog color by when running in HDR mode.

Zoom Fog Scale <float> = 1

How much the fog min/max values will scale the default value by when players are zoomed in (scoped).
